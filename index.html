About this estimate

The result comes from a linear regression model with L1 regularization (Lasso). It learns how age, body measurements, workout duration, heart rate and body temperature relate to calories burned. In this project, duration and heart rate were the strongest predictors.

How it works

Your input goes through the same steps used when the model was trained.

1. Input

You enter your details. The browser checks the values and sends them to the API.

2. Preprocessing

Gender is one-hot encoded and all features are standardized with the saved encoder and scaler.

3. Model

The trained Lasso regression model calculates the predicted calories.

4. Result

The API returns the value and this page displays it in kilocalories.

Model inputs

The model uses these seven features from the dataset.

Gender

Female or male, encoded as two columns.

Age

Age in years.

Height

Height in centimeters.

Weight

Body weight in kilograms.

Duration

Length of the workout in minutes.

Heart Rate

Heart rate during exercise in beats per minute.

Body Temp

Body temperature during exercise in degrees Celsius.
