# CalorieIQ - Calories Burn Prediction

A machine learning web application that predicts calories burned during physical activity using physiological and workout-related features.

## Overview

CalorieIQ uses an Encoder-Decoder pipeline:

**Input → Encoding & Scaling → Regression Model → Calories Prediction**

The project compares different regression models using R², MAE, and MSE.

> 🌍 **Live Demo:** [Try CalorieIQ on Vercel](https://calorie-burn-prediction-one.vercel.app/)

## Features

- Gender
- Age
- Height
- Weight
- Workout Duration
- Heart Rate
- Body Temperature

## Models & Results

| Model | R² | MAE | MSE |
|---|---:|---:|---:|
| Linear Regression | 0.8940 | 13.87 | 410.65 |
| Gradient Descent | 0.8926 | 14.16 | 415.93 |
| Ridge | 0.8940 | 13.87 | 410.66 |
| Lasso | **0.8941** | **13.87** | **410.03** |
| ElasticNet | 0.8922 | 14.39 | 417.33 |

Lasso Regression achieved the highest R² and the lowest MAE and MSE in this evaluation.

## How It Works

1. User enters their physiological and workout information.
2. Gender is transformed using One-Hot Encoding.
3. Features are standardized using the saved scaler.
4. The trained regression model predicts calories burned.
5. The Flask API returns the prediction to the web interface.
